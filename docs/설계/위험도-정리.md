# 위험도 정리

위험도의 변수·가중치·자료·계산 방식을 정리하는 문서입니다. 위험도 관련 내용은 이 문서에서 계속 관리합니다.

| 항목 | 내용 |
|---|---|
| 최종 갱신 | 2026-10-26 |
| 기준 | AI Hub 위험도 기준표 CSV(25개 변수), 수정 요구사항 분석서(23개, P5 기준), 「산불 발생 후 위험도 정의」(김지오, 10/5) |
| 관련 문서 | [`DB-설계.md`](DB-설계.md), [`데이터-자원.md`](데이터-자원.md) |

## 계산식

```
R = Σ(가중치 × 등급) ÷ Σ가중치        등급 1~5, R 1.00~5.00
```

- 23개 변수의 CSV 가중치 합은 0.94다(경사도_down 0.03·도로 접근성 0.03 제외). **재조정 가중치** = CSV 가중치 ÷ 0.94
- 구할 수 없는 변수는 빼고 남은 가중치로 나눈다

**상태** ✅ 자료가 있고 바로 등급을 매길 수 있음 · 🟡 자료는 있으나 변환 규칙·추가 수집·정의 확인이 필요 · ❌ 자료 없음

## 정해야 할 것

- 기상 값의 칸: P5에 걸친 예보 격자별(김지오 문서) / `predictions.weather` 한 지점
- 기상 값의 시각: P5 시점(0시 + 5시간) / 0~5시간 평균
- 지형·연료 격자 칸 크기: 30 m / 100 m
- 취약계층 범위: 65세 이상 + 0~14세(수정 분석서) / 65세 이상 + 시설 입소자(김지오 문서)
- 소방서 거리 기준: 현재 화선 경계(김지오 문서) / P5 경계
