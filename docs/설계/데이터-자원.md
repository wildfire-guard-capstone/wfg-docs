# 데이터 자원

서비스에 필요한 데이터를 **어디서 가져와 어디에 쓰는지, 지금 있는지, 누가 구해 어디에 두었는지** 한 표로 관리합니다(10/16 회의 결정).

- **상태**와 **확보자 · 위치**는 데이터를 **직접 확보한 사람이 채웁니다.** 비어 있으면 아직 확인되지 않은 것입니다.
- 데이터를 새로 구하거나 상태가 바뀌면 이 표를 고치고 PR로 올립니다.

| 위치 기준 | 공유 데이터 폴더 `capston-data/` (이 저장소에는 데이터 파일을 올리지 않음) |
| 관련 문서 | [`DB-설계.md`](DB-설계.md) · 지도·자원 폴더 설명 `data/지도자원/README.md` [M-9] |

## 메모

꼭 필요한 설명만 ID별로 남깁니다.

- **[M-1] 바탕지도(D-01)** — 가입·키 없이 MapLibre에 스타일 URL만 넣으면 됨. 화면에 「OpenFreeMap © OpenMapTiles Data from OpenStreetMap」 표기 필수. 서비스 보장(SLA)이 없어 필요하면 지도 파일을 받아 자체 서버에 둠
- **[M-2] 인구 N/A(D-04)** — 개인정보 보호로 작은 값이 「N/A」로 가려져 있음(의성 5,651칸 중 1,347칸, 약 24%). 65세 이상은 오차 2% 안팎이지만 0~14세는 최대 20% 적게 잡힘. 리별 추정에서는 비율을 **가려지지 않은 칸의 합으로 나눠** 치우침을 줄임. 연령 코드는 합계로 맞춤: `in_age_001~021` = 남녀 합계 5세 단위(001 = 0~4세 … 014 = 65~69세 … 021 = 100세 이상), 031~051 = 남자, 061~081 = 여자. SGIS 코드집으로 한 번 확인 필요
- **[M-3] 집계구(D-03)** — 면 지역은 집계구가 커서(의성 98개 < 리 182개, 최대 59㎢) 면적만으로 나누면 인구가 산지에 고르게 퍼짐 → 리별 65세 이상·0~14세는 **리 인구(D-05, 2025-02) × 겹친 집계구 비율(겹친 면적 가중)**으로 추정함(`스크립트/build_oa_age.py`·`build_load.py`). 같은 면 안 리들은 비율이 비슷하게 나옴(안평면 55~58%). 의성 합계 65세 이상 약 50%로, SGIS 원자료 합(47%)보다 조금 높음
- **[M-4] 마을(D-06·D-07)** — 마을 단위는 **법정리**로 함(행정리는 공식 경계가 거의 없음). 판정은 화선·P5·P8이 **리 영역과 겹치는지 + 겹친 비율**로 함(10/29). 리별 인구(D-05)와 법정동코드 10자리로 연결. 리 영역 안에 산이 넓게 들어가 있어 겹친 비율이 작은 리는 실제 주거지에 불이 안 닿을 수 있음 → 한계로 기록
- **[M-5] 연료 빈칸(D-19·D-20)** — 임상도는 산림만 그려서 의성 면적의 약 34%(논·밭·시가지·하천)가 비어 있음. ELMFIRE 연료 격자는 빈칸 없이 채워야 하므로, 토지피복지도로 「타지 않는 곳」과 「풀·농경지」를 나눠 채워야 함. 산지 면은 77~85%, 평야 면(안계 38%, 단북 6.7%)은 낮음
- **[M-6] 기상(D-25~D-27)** — 예보는 공공데이터포털(앞으로의 날씨), 관측은 기상청 API허브(지난·현재 날씨)에서 받음. 운영에서 확산 예측은 예보를 쓰고, 시연·평가는 과거 날짜라 예보를 받을 수 없어 AWS 관측을 씀. 연료 수분(최근 습도)과 위험도의 7일 누적 강수량은 운영 중에도 관측이 필요함. 위험도 기상 7변수(기온·강수량·풍속·상대습도·기압·지면온도·7일 누적 강수량) 중 **기압·지면온도는 예보에 없어** 현재 관측값을 씀(P5 시점 값이 아님 → 한계로 기록). ASOS는 관측소가 적어(전국 약 100곳) 가장 가까운 ASOS 관측소 값을 씀
- **[M-7] 의성 ELMFIRE 재현 사례(D-18~D-24·D-27·D-37·D-39)** — 코드·설정·ASOS CSV는 `wfg-server`의 `feature/uiseong-elmfire-example` 브랜치에 있고, 재배포하지 않는 DEM·WorldCover·임상도 원본은 별도 보관함. 지형과 임상도 원자료는 확보했지만 연료모델 매핑, 연료수분, CC·CH·CBH·CBD는 연구용 변환·추정값이다. 공간 바람장과 실제 시계열 화선은 확보하지 못했으므로 운영 정확도가 검증된 자료로 간주하지 않음
- **[M-8] 법령·규정 근거 코퍼스(D-34·D-35)** — 표준매뉴얼 p.10 「관련 법규」에 적힌 37건 중 36건을 국가법령정보센터 Open API로 받음(법령 27건·관련 지침 9건, 읽기용 txt·원본 xml·별표 PDF). 국가위기관리기본지침(대통령훈령)은 공개 원문이 없어 미확보. 조문·항·별표 행 단위 청크 4,176개를 PostgreSQL 근거 테이블에 넣었고, 근거 법령·관련 지침 청크 1,475개만 KURE-v1·FAISS로 색인해 A6000 서버에 배포함. 관계 법령은 산불 판단과 관련된 조항이 적어 검색에서 뺐음([`LLM-입력-정리.md`](LLM-입력-정리.md) L-11)
- **[M-9] 지도·자원 폴더(D-02~D-15·D-40~D-42)** — `data/지도자원/` 아래 `원본/`(받은 그대로, 출처_기준일 폴더) → `의성/`(의성만 자른 레이어) → `적재/`(DB 테이블 1개 = 파일 1개: `admin_areas.geojson` 19 · `villages.geojson` 182 · `facilities.csv` 220 · `resources_헬기_시연.csv` 20). 점 시설은 `facilities` 한 표에 `type`(shelter · vulnerable · hospital · fire_station · police · heritage)으로 넣고, 종류별 칸은 `attrs`(jsonb)에 둠. 한 건물 = 한 행(응급 이송처는 `attrs.emergency`). `스크립트/전부_다시만들기.sh`로 원본부터 다시 만들 수 있음
