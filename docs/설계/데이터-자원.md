# 데이터 자원

서비스가 동작하는 데 필요한 데이터 자원과 확보 현황을 정리한 문서입니다. DB 설계 B(지역·정적 레이어)는 이 문서에서 **실제로 구할 수 있는 데이터**를 확인한 뒤 진행합니다.

> 「자원」이 진화자원(헬기·차량·인력)과 헷갈리지 않도록, 이 문서에서는 시스템이 쓰는 자료를 **데이터 자원**이라고 부릅니다. 진화자원 데이터도 데이터 자원의 하나로 포함합니다.

## 메타 정보

| 항목 | 내용 |
|---|---|
| 상태 | 초안 — 확보 현황은 회의록 기록과 받은 파일 직접 확인(2026-10-16) 기준이며 팀 확인 필요. `[x]`는 파일을 직접 열어 확인했거나, 회의록·문서에 「확보했다」·「직접 사용했다」는 기록이 있는 것만 표시 |
| 작성일 | 2026-10-16 |
| 기준 문서 | 수정 요구사항 분석서(기능·데이터셋 표·참고문헌), 프로토타입 보고서, 회의록 2·4·6·7주차 |
| 관련 문서 | [`DB-설계.md`](DB-설계.md) |
| 데이터 보관 위치 | 팀 공유 데이터 폴더 `capston-data/data/` (이 저장소에는 올리지 않음) |

## 1. 서비스를 데이터 흐름으로 다시 보기

산불이 보고되면 아래 순서로 처리되고, 단계마다 필요한 데이터가 다릅니다.

| 단계 | 하는 일 | 필요한 데이터 자원 |
|---|---|---|
| ① 보고 | 상황 보고자가 발화 위치·신고 정보·실측 화선을 입력 (F-02) | 바탕지도, 행정경계 |
| ② 확산 예측 | ELMFIRE가 실측 화선(없으면 발화점)에서 1시간 간격 P1~P8 계산 (F-09) | **지형(DEM)**, **연료(임상도 → 연료 모델·연료 파라미터)**, **기상**(풍향·풍속·습도) |
| ③ 위험도 | P5 범위의 23개 변수로 위험도 R 계산 (F-10) | **위험도 기준표**, 기상·지형·연료 값, **인구(연령별)**, **소방서 위치** |
| ④ 규칙 판정 | 예측 범위에 든 마을·시설·도로를 찾아 대응단계·위험구역·대피소 배정 등 판정 (F-15~F-28) | **마을**(위치·인구·취약계층), **시설**(대피소·취약시설·국가유산·담수지·송전시설·소방서·파출소·유관기관), **도로·대피로**, **진화자원** |
| ⑤ 근거 검색·제안 작성 | 매뉴얼에서 근거를 찾아 제안 문장 작성 (F-11, F-13) | **근거 문서**(표준매뉴얼·실무 매뉴얼·규정·법령) |
| ⑥ 평가 | 예측과 제안의 성능을 하한선과 비교 (TER-002) | **실측 소실 경계·시계열 화선**, **평가 정답 답변** |
| 시연 | 2025-03-22 의성 산불로 전 과정을 보여 줌 | **의성 산불 경과 자료** |
