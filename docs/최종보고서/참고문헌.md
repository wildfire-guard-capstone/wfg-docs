# 참고문헌 (최종보고서 공용)

최종보고서 원고에서 쓰는 출처를 한곳에 모은 목록입니다. 원고에서는 `[R01, p.21]`처럼 **고정 번호**로 인용하고, 최종보고서를 쓸 때 등장 순서대로 번호를 다시 매깁니다.

| 상태 | 뜻 |
|---|---|
| ✅ 원문 대조 | 원문을 직접 읽고 인용 문장을 글자 단위로 확인함 |
| ⚠️ 재인용 | 다른 문서에 인용된 내용만 확인함. 원문은 보지 않음 |
| ☐ 미확인 | 원문을 아직 보지 않음 — 본문에 쓰기 전에 확인 필요 |

- **확인**: PDF 전문(30쪽) 텍스트 추출 후 대조, 2026-10-16
- **원문 위치**: Obsidian `Project/2026-capstone/산불/요구사항 명세서/발표/` 안의 PDF (파일명이 `\.pdf`로 깨져 있음 — 이름 바꿀 것)
- **쪽 표기**: PDF 쪽 = 인쇄 쪽 (표지 요약이 1쪽). 경진대회 제출 문서의 TF 쪽수는 한 쪽씩 앞당겨져 있으므로 이 목록 기준으로 다시 맞춘다
- **주의**
  - 개정 전 「산림보호법」 기준으로 쓰였다. 「산림재난방지법」(2026.2.1 시행)과 "사실상 큰 차이는 없어 보인다"(13쪽)고 하지만, 지휘권·대응 단계는 현행 조문으로 다시 확인한다
  - 산림청장 지휘 조건이 보고서 안에서 다르게 적혀 있다 — "초대형산불(1,000만㎡ 이상)"(6쪽), "둘 이상의 시·도"(20쪽), "둘 이상 시·도 / 1,000ha 이상 / 24시간 이상"(표 9 21쪽, 각주 40 27쪽)
  - 그림 3의 대응 단계(초기대응 + 산불 1~3단계)는 개정 전 산림청 발령기준이다
- **쓰는 곳**: 1.1, 1.2(문제 ②, 보류한 문제 ③), 1.3

### R03 YTN 사이언스 기사 ✅

- **서지**: 정혜윤, 「'산불 예보' 적중했지만…'확산 예측 시스템' 역부족」, YTN 사이언스 〈사이언스 투데이〉, 2025.4.9.
- **URL**: https://m.science.ytn.co.kr/program/view_today.php?key=202504091114479947
- **확인**: 기사 HTML 원문 대조, 2026-10-16
- **발언자 구분**
  - 기자 서술 — "현장에서의 대응 시스템이 산불 확산 속도를 따라가지 못했기 때문입니다", "산불 예측 경로를 과학적으로 분석해 실시간으로 현장에 제공하는 조직도 극히 소수 인력이라 장시간 산불에 대응하기가 어려운 것도 문제입니다"
  - 원명수 국립산림과학원 국가산림위성정보 활용센터장 — 확산 예측은 구동됐으나 "초속 (27m 정도의) 순간 최대 풍속이 실제로는 예상이 안 됐습니다"
  - 이병두 국립산림과학원 산림재난환경연구부장(YTN 재난자문위원) — "실시간으로 산불의 화선을 탐지하고, 그게 (산불 확산) 예측에 들어가고, (그 정보가) 대피 권역을 설정하고, (그 정보가) 또 대피 문자를 발령하는 그 시스템이 자동화해야 하는 거죠. 자동화가 중요한 건 너무 확산 속도가 빠르잖아요."
- **주의**
  - 제목의 "적중한 예보"는 확산 예측이 아니라 국립산림과학원의 **봄철 산불 *발생* 위험 예측**(2월 말 발표)이다
  - 기사의 중심 주장은 **예측 정확도**(강풍·산악 기상 관측)다. "현장 대응 시스템이 확산 속도를 못 따라갔다"의 이유로 기사가 드는 것도 강풍 예측 실패다
  - 기사에는 "수작업", "별도 시스템", "시간대별 확산 속도·방향, 주요 시설 도달 시간"이라는 내용이 없다 — ②·③·⑤와 경진대회 문서가 이 기사를 출처로 단 문장 중 일부는 출처 표기 오류
- **쓰는 곳**: 1.2 문제 ①

### R04 국립산림과학원 보도자료 ✅ (본문) / ☐ (첨부 hwp)

- **서지**: 국립산림과학원, 「AI로 정확하게! 산불확산예측시스템 재난 현장으로 연결 — 국립산림과학원, 'AI 융합 산불확산예측 발전 방향' 심포지엄 개최」, 보도자료, 2025.10.2. (작성: 연구기획과)
- **URL**: https://www.forest.go.kr/kfsweb/cop/bbs/selectBoardArticle.do?nttId=3211805&bbsId=BBSMSTR_1036&mn=NKFS_04_02_01
- **확인**: 산림청 누리집 게시 본문 대조, 2026-10-16. 첨부 hwp 원문은 미확인
- **인용할 수 있는 문장**
  - "산불확산예측시스템은 2003년 최초 개발된 이후 지속적으로 고도화되어 왔으며, 현재는 주민 대피 판단과 진화 전략 수립 등 현장의 핵심적인 의사결정에 활용되어 산불 대응의 속도와 효율성을 높이고 있다."
  - 학계·언론·실무 전문가 토론 의제: "▲예측모델의 실시간 운영체계 구축 ▲기상 등 입력 자료의 표준화 플랫폼 마련 ▲지방자치단체 현장 매뉴얼 과의 연계 방안"
  - 김용관 원장: "AI 기반 확산예측 기술과 현장 전문지식을 결합하여 주민 안전을 지키고 진화 효율성을 높이겠다", "연구 성과를 현장에 신속히 적용하고 조기 대응 역량을 강화하겠다"
- **주의**
  - 게시 본문에는 "시간대별 확산 속도와 방향, 주요 시설물 도달 시간, 예상 피해 면적 산출"이 없다. ① 제안서가 이 문장에 이 보도자료를 출처로 달았는데, 첨부 hwp에 있는지 확인 전까지 쓰지 않는다
  - 토론 의제는 "토론을 진행했다"는 서술이다. "부족하다"는 직접 진술이 아니므로 "과제로 논의되고 있다"까지만 쓴다
  - 예측이 이미 현장 의사결정에 쓰인다는 정부 공식 서술이다. 본 과제는 "예측이 쓰이지 않는다"고 쓰지 않는다
- **쓰는 곳**: 1.2 문제 ①

### R05 산림청 산불방지과 서면 답변 ☐

- **서지**: 산림청 산불방지과, 5조 서면 질의에 대한 답변, 2026.9.
- **확인**: 답변 원문 미확인. 9/28 발표구성안과 경진대회 문서 표 2에 정리된 요지만 확인
- **요지(정리본 기준)**: 진화 우선순위는 법령에 따라 인명 → 국가기간시설 → 가옥·재산 → 산림자원 순. 자원 배분은 별도 기준표 없이 주어진 자원과 진행 상황을 판단해 배치. 확산 예측은 주민대피에 적극 활용(5시간 도달권은 즉시 대피 명령), 자원 배치·단계 격상에도 일부 고려. 산불분석·자원배치·진입로 분석 등 대응 관련 용역 추진 중. AI는 참고용, 국내 모델을 내부 서버에 두는 방안 연구 중
- **주의**: 개인 의견이라는 전제로 받은 답변이다. 문제 ②를 **설명하는 보조 사례**로만 쓰고, 입증 근거로 쓰지 않는다. "기준표가 없다"고 단정하지 않는다
- **할 일**: 답변 원문(메일·문서) 위치를 찾아 이 항목에 적는다
- **쓰는 곳**: 1.2 문제 ②
