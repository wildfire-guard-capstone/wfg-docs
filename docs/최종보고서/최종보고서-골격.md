## 1. 서론

> **1장 흐름** — 방향 전환은 ②→③에서 한 번 크게 일어났다(대상이 통합지휘권자 1인으로 바뀜). ③→④는 서론 변화 없음(일정 행만 수정), ⑤는 ③ 01장을 거의 그대로 쓰고 「업무 설명서」(슬라이드 8)만 더했다.

### 1.2 현행 대응 체계의 문제점 🟡

- **골자(현재)**: → [1-서론.md §1.2 요약](1-서론.md#12-현행-대응-체계의-문제점)
- **서술 원천**
  - ② 3.1 표 3-1 — 현행 국가 시스템 3종(국가산불위험예보·국가산불정보·산불확산예측), 대응 단계 기준(초기 10ha 미만 / 확산 1단계 10~100ha / 2단계 100ha 이상), 법 제34조 통합지휘, 정부 2026 「AI 기반 산불·연무 확산 예측」 사업과의 위치 비교. ③에서 한 줄 표로 압축됨 → **최종보고서에서 되살려야 할 핵심 근거**
  - ② 1.2 — 확산이 대응보다 빠르고, 장시간 누적되고, 주체마다 필요한 임무가 갈린다는 "세 가지 한계". 문제 ②의 보조 논거로 쓸 수 있음

  - **TF 보고서**(국회입법조사처, 제355호, 2025.6.27.) Ⅴ.1·Ⅴ.2 — 지자체장 중심 지휘권, "현장 경험이 거의 없는" 지휘권자, 이원화·협력 비효율. ③⑤가 출처로만 적고 내용은 거의 쓰지 않음
  - 9/28 발표구성안(Obsidian `요구사항 명세서/발표/산불_프로젝트_1-2장_발표구성.md`) — 문제 ①② 문구, 실무자 질의 사례와 사용 범위 메모
- **변천**: ① 두 공백(번역되지 않는 예측 / 사람 손의 번역) → ② "예측→대응 자동 연결 부재 + 소수 인력 수작업"(✏️, 지휘체계 논거 삭제 ② #2) → ③ "분산 정보 + 지휘권자 전문성 한계"(🔄, 지휘체계 이원화 논거 ♻️) + 비어 있는 단계를 표로 명명(⬆️) → ⑤ 동일 → **원고(10-16)**: 근거를 TF 보고서 Ⅴ장 원문으로 보강(⬆️), 실무자 질의 사례를 문제 ②의 보조 사례로 추가(➕), "비어 있는 단계" 표는 문제점이 아니라 과제의 위치라서 1.5 차별성으로 이동 → **원고(10-16 2차)**: 문제 ①을 "기관별 분산된 자원·상황정보"에서 "예측에서 대피 판단까지 이어지는 과정이 자동화돼 있지 않고, 이를 맡는 분석 조직은 극소수 인력"으로 교체(🔄, 근거 YTN 2025.4.9 — HTML 원문 대조 후 "수작업"·"확산 속도를 못 따라감"·기관 명의 인용을 걷어 냄. 근거 1건이라 잠정안). ②의 "예측과 대응 사이 연결고리 부재" 논리의 ♻️ 부활. 기존 문제 ①은 근거 부족으로 문제 ③(보류)으로 내림 — 이유는 원고 1.2에 정리
