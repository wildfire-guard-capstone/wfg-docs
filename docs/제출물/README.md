## 폴더 규칙

- `docs/제출물/<N주차>-<문서종류>/` 형태로 주차별 폴더를 둔다.
- 새 제출물이 생기면 폴더를 추가하고 위 표를 갱신한다.
- 각 폴더에는 원본(docx/pptx)과 함께 `캡스톤디자인(N주차)-<문서종류>-정리.md`를 둔다. 원본 목차를 그대로 따라 내용을 옮긴 문서로, 원문에 없는 보충은 `(정리자 주)`로 구분한다.
