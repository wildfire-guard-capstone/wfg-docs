### 1. 목업 링크

HTML 파일: `wildfire_decision_support_mockup_v18_predictionbar_moved.html` (이 폴더)

대상: **산불 확산 예측 결과와 표준매뉴얼 기반 진화·대피 대응을 통합지휘본부장에게 제안하는 의사결정 지원 화면**

시연 시나리오는 **2025년 경북 의성군 안평면 괴산리 산불**을 기준으로 구성했습니다.

### 2. 서비스 정의

산불 발생 시 시장·군수·구청장 등 산불현장 통합지휘본부장이 한 화면에서

**산불 발생 정보 → 확산 예측 → 위험 대상 확인 → 유관기관 확인 → 진화·대피 대응 제안**

을 확인할 수 있도록 구성한 의사결정 지원 서비스입니다.

챗봇에 먼저 질문해서 정보를 찾는 방식보다는, 시스템이 현재 상황과 확산예측 결과를 분석해 **필요한 대응을 먼저 제안하는 구조**를 중심으로 설계했습니다.

AI 어시스턴트는 메인 기능이 아니라, 현재 제안된 대응이나 근거를 추가로 질문할 때 사용하는 보조 기능으로 두었습니다.

### 3. 주요 사용자

주 사용자는 **시장·군수·구청장 등 산불현장 통합지휘본부장**을 기준으로 했습니다.

현장 진화대원이나 소방·경찰 등 유관기관이 직접 시스템에서 의사결정을 내리는 구조보다는, 통합지휘본부장이 상황을 종합적으로 판단하고 각 기관에 필요한 대응을 전달하는 흐름을 가정했습니다.

### 4. 화면 구성

| 영역 | 내용 |
| --- | --- |
| 중앙 지도 | 산불 발생지, 확산예측, 시설, 대피 관련 정보, 유관기관 표시 |
| 지도 좌측 상단 | 현재 / +1h / +3h / +5h / +8h 확산예측 선택 |
| 확산예측 컨트롤 | 여러 시점 중첩, 시간대별 재생, 전체 보기 |
| 지도 우측 | 지도 레이어 ON/OFF |
| 산불 발생정보 | 주소, 발생시각, 신고, 기상, 진행상태 등 표시 |
| 유관기관 | 소방, 경찰, 지자체, 산림 대응기관 위치 표시 |
| 대응 제안 | 요약 / 진화 / 대피 3개 탭 |
| AI 어시스턴트 | 현재 대응 제안이나 근거를 추가 질문하는 플로팅 채팅창 |

### 5. 확산 예측 기능

확산예측은 일반 지도 레이어와 분리해서 지도 좌측 상단에 배치했습니다.

확산예측 시점은 `현재 F0 / +1h / +3h / +5h P5 / +8h P8`로 구분했습니다.

각 시점을 개별적으로 선택할 수도 있고, 여러 예측 시점을 동시에 겹쳐서 볼 수도 있습니다.

`재생` 버튼을 누르면 현재 화선부터 +8시간까지의 확산 과정이 순서대로 표시됩니다.

확산예측 시점을 변경하면 오른쪽의 **대응 제안 요약도 함께 변경**되도록 구성했습니다.

즉, **확산예측 변화 → 영향 대상 변화 → 대응 우선순위 변화**를 하나의 흐름으로 확인하는 것이 핵심입니다.

### 6. 지도 레이어

확산예측 외의 정보는 지도 레이어로 분리했습니다. 주요 레이어:

- 기상
- 지형·연료
- 인구·대피
- 도로·접근
- 국가·주요시설
- 문화재·산림자원
- 유관기관

시설은 지도에서 하나씩 직접 찾지 않아도 현재 몇 개가 있는지 빠르게 확인할 수 있도록 일부 항목에 숫자 뱃지를 표시했습니다.

예: `국가유산 1` `군사시설 1` `전력시설 2` `취약시설 2`

### 7. 유관기관 표시

지도에서 산불 대응과 관련된 주변 기관을 확인할 수 있도록 별도의 유관기관 레이어를 만들었습니다.

현재 분류: 소방기관 / 경찰기관 / 지자체·상황실 / 산림·진화지원기관

각 기관은 지도에 마커로 표시되고, 마커 클릭 시 기관명·역할·담당 권역·연락 정보·가용 자원을 확인할 수 있습니다.

예를 들어 경찰기관은 주민대피 지원과 교통통제, 소방기관은 진화·구조·구급 등의 역할을 확인할 수 있도록 했습니다.

현재 목업에 들어간 기관별 장비와 인력 숫자는 일부 **시연용 가상 데이터**입니다.

### 8. 대응 제안

지도 오른쪽에 **대응 제안** 영역 배치. 구성은 `요약 | 진화 | 대피` 3개 탭.

#### 요약

현재 상황에서 전체 대응 상태를 한눈에 볼 수 있도록 구성.

예시: `즉시 9 | 대기 2 | 협의 1 | 요청 2 | 보고 0 | 근거 부족 0(부분 1: S3) | 정보 부족 0 | 없음 3`

선택한 확산예측 시점에 따라 **현재 우선 대응 항목**과 **직전 시점 대비 변화**를 함께 표시.

예를 들어 +5시간 P5를 선택했을 때 위험마을이나 보호시설이 새롭게 확산범위에 들어오면, 그에 따라 대피나 시설 보호와 관련된 대응을 우선적으로 보여주는 방식입니다.

### 9. 진화 대응 (S1~S7)

| ID | 내용 |
| --- | --- |
| S1 | 대응단계 판단·격상 검토 |
| S2 | 진화 우선지역·보호대상 선정 |
| S3 | 진화자원 투입·배분·재배치 |
| S4 | 진화 방식·시간대 전략 |
| S5 | 시설 보호 조치 |
| S6 | 유관기관 동원·협조 요청 |
| S7 | 진화인력 안전·투입 관리 |

각 항목에서 최종적으로 현재 판정 / 제안 이유 / 권한 / 필요정보 / 표준매뉴얼 근거를 확인할 수 있도록 구성.

### 10. 대피 대응 (E1~E7)

| ID | 내용 |
| --- | --- |
| E1 | 위험구역 설정 |
| E2 | 대피 명령 대상·순서·시점 |
| E3 | 취약시설·미대피 주민 조치 |
| E4 | 대피소 배정·분산 |
| E5 | 대피 경로·교통통제 |
| E6 | 전파(재난문자·방송) |
| E7 | 인명구조·긴급구조 요청 |

진화와 동일하게 각 항목에서 판정 결과와 근거를 확인할 수 있도록 구성.

### 11. AI 어시스턴트

오른쪽 하단에 **AI 어시스턴트 플로팅 버튼** 배치.

AI가 전체 서비스를 대신하는 구조가 아니라, 시스템에서 이미 생성된 대응 제안을 추가로 이해하는 용도.

질문 예시:

- 지금 가장 먼저 해야 할 대응은?
- 5시간 뒤 위험지역은?
- 유관기관에는 무엇을 요청해야 해?
- 이 대응의 근거는 무엇인가?

현재 목업에서는 정해진 질문에 대한 시연용 응답만 제공. 실제 구현에서는 현재 확산예측 결과, 선택한 S/E 대응 항목, 판정값, 표준매뉴얼 근거를 AI의 컨텍스트로 전달하는 방향.

### 12. 주요 화면 흐름

**산불 발생** → 산불 발생·신고 정보 확인 → 시간대별 확산예측 확인 → 확산 예상 범위와 시설·마을·도로 확인 → 주변 유관기관 및 가용자원 확인 → 시스템이 대응 제안 갱신 → 요약에서 우선 대응 확인 → 진화 S1~S7 / 대피 E1~E7 세부 판단 확인 → 필요하면 AI 어시스턴트로 근거 및 제안 내용 추가 질문

### 13. 현재 목업의 실제/가상 데이터 구분

| 데이터 | 구분 |
| --- | --- |
| 의성군 안평면 괴산리 산불 사례 | 실제 사례 기반 |
| 산불 발생 지역·시간 등 기본정보 | 실제 공개자료 기반 |
| 확산예측 P1~P8 | 목업용 예측 데이터 |
| 주택·국가유산·군사·전력시설 등 위치/개수 | 일부 목업 데이터 |
| 유관기관 위치 | 실제 기관을 참고한 시연 데이터 |
| 유관기관 장비·인력 수량 | 가상/시연용 데이터 |
| S1~S7 / E1~E7 분류 | 표준매뉴얼 기반 |
| 대응 제안 | 규칙 기반 목업 |
| AI 답변 | 시연용 응답 |

현재 단계에서는 **실제 데이터와 UI 구조를 검증하기 위한 목업**에 초점을 맞췄고, 이후 실제 데이터 연동 시 가상 값을 API 및 실제 공간데이터로 대체할 예정입니다.

### 14. 구현 상태

현재는 단일 HTML 기반의 화면 목업. 주요 인터랙션:

- 확산예측 시점 ON/OFF · 시간대별 확산 재생 · 확산예측 전체 보기
- 지도 확대/축소 · 이동 · 레이어 ON/OFF · 레이어 패널 축소
- 산불 정보 팝업 · 유관기관 마커 클릭 · 기관 자원정보 확인
- 대응 제안 탭 전환 · 확산예측과 대응 요약 연동 · AI 어시스턴트 팝업
