캡스톤디자인 5조

**의성군 산불 확산·의사결정 제안 시스템**

**목업(Mock-up) 기능 정리 문서 · v0.6**

1\. 개요

이 문서는 지금까지 만든 HTML 목업(claude.ai 아티팩트로 배포)의 기능을
정리한 문서다. 목업은 「산불 확산 예측과 근거 기반 대응 의사결정 지원
시스템」 수정계획서(5조)와 9/24 회의에서 확정한 서비스 대상·의사결정
항목·출력 계약을 반영해 만들었다.

1.1 서비스 정의

| **구분** | **내용** |
|----|----|
| 서비스 대상 | 개인 1인 — 초기대응·확산대응 1단계의 의성군수(산불현장 통합지휘본부장 겸 주민대피 명령권자, 표준매뉴얼 p.72·p.84) |
| 입력 | 발화 위치(F0), 발화 시각, 예측 실행 트리거 |
| 예측 스냅샷 | P5(t0+5시간 확산 폴리곤, 필수) · P8(t0+8시간 확산 폴리곤, 권장) |
| 출력 | 고정 형식 의사결정 제안서 — 14개 항목(S1~S7 진화, E1~E7 대피), 항목당 판정/구분/제안/대상/충돌/근거 6줄 |
| 데모 지역 | 경상북도 의성군 (1읍 17면, 18개 읍·면) |
| 데모 시나리오 | 2026-03-22 발화, 발화지점은 지도 클릭으로 지정 가능(기본값 안평면 인근) |

2\. 화면 구성

화면은 상단 컨트롤 영역과 3열 본문(사이드바·지도·책임자), 하단 전체너비
영역(제안서·근거각주), 우하단 플로팅 챗봇으로 구성된다.

| **영역** | **위치** | **설명** |
|----|----|----|
| 상단바 | 최상단 고정 | 발화 위치 표시 + 지도에서 지정 버튼 + 현재 위치(GPS) 버튼, 발화 날짜(캘린더)·시각(알람식 시/분 스테퍼), 예측 실행 버튼 |
| 타임라인 바 | 상단바 아래 | 현재 시각(t0) 슬라이더 — 이동 시 P5=t0+5h, P8=t0+8h로 자동 재계산 |
| 지역 감시 현황 | 좌측 사이드바 | 경북 \> 의성군 경로 표시, 정상/주의/위험/화재 개수 요약, 읍·면 18개소 상태 리스트(반경 기준 자동 분류) |
| 확산 예측 지도 | 중앙 | 사용자 제공 실제 도로망 지도 배경, 산 위치 오버레이, 지형/기상/연료/인프라 레이어 토글, 확산 범위 애니메이션, 조건위험도 게이지 |
| 책임자 | 우측 | 의성군수 고정 배너(통합지휘본부장 겸 주민대피 명령권자) |
| 의사결정 제안서 | 하단 전체너비 | 14개 항목 블록, 구분 토큰 범례, 헤더(현재시각·책임자·규칙판정단계), 요약 카운트 |
| 근거 각주 | 하단 전체너비 | 표준매뉴얼 조항 17개, 제안서·챗봇 답변에서 공통 인용 |
| 챗봇 | 우하단 플로팅 | 열기/닫기 토글, 화면에 표시된 근거자료만 사용하도록 제한된 근거 기반 Q&A |

3\. 기능 상세

3.1 발화 위치 지정

- 텍스트 입력 없이 두 가지 버튼으로만 지정: 「지도에서 지정」, 「현재
  위치」

- 지도에서 지정: 버튼을 누르면 현재 위치 마커가 지도 위에서 강조되고,
  지도를 클릭하면 그 좌표로 즉시 재배치(스탬프 효과)되며 가장 가까운
  읍·면 이름으로 자동 라벨링

- 현재 위치: 브라우저 GPS 좌표를 읽어, 의성읍·다인면 두 실좌표로 보정한
  위경도↔픽셀 변환식을 통해 지도 위 위치에 표시. 의성군 범위 밖이면
  좌표를 안내하고 지도 클릭 지정을 권함

- 위치가 바뀌면 이전 예측 결과는 초기화되고 재실행이 필요

3.2 발화 시각 입력

- 날짜: 브라우저 기본 달력 위젯(input type=date)

- 시각: 알람 설정과 같은 방식 — 시(HH)·분(MM) 옆의 ▲▼ 버튼으로 1단위
  증감(0~23시, 0~59분 순환)

3.3 예측 실행 · 조건위험도

- 예측 실행 버튼을 누르면 ELMFIRE 연산을 흉내 낸 로딩 후, 발화 위치
  좌표를 시드로 한 의사난수로 기상·지형·연료·인프라 4요인 값을
  산출(가중치 0.35/0.30/0.25/0.10)

- 조건위험도는 발화 시점 조건으로 1회만 계산되며, 이후 타임라인을 옮겨도
  값이 바뀌지 않음 — 지점을 바꿔 다시 실행하면 다른 값이 나옴

- 반원형 스피드미터 게이지(정상=teal/주의=amber/위험=red 3색 밴드)로
  표시, 바늘과 상태 배지가 함께 표시됨

3.4 확산 예측 지도

- 사용자가 제공한 의성군 실제 도로망 지도(국도·고속국도·철도·지방도
  표기)를 배경 이미지로 사용

- 사용자가 제공한 관광지도에서 산(비봉산×2, 갈라산, 청화산, 금성산)
  위치만 판독해 겹쳐 표시

- 체크박스로 켜고 끄는 4개 레이어: 지형(고지대 등고선),
  연료(산림/농경지/시가지 3분류 색상 구역), 기상(풍향 화살표),
  인프라(시설·인구 밀집도 사각 마커) — 위험도 4요인과 1:1로 대응

- 확산 범위는 발화지점을 중심으로 한 단일 원으로 표시되며, 시간 경과에
  따라 반경이 매끄럽게 커지고 색이 밝은 주황→짙은 적갈색으로 변함

- 확산이 행정경계에 근접하면 점선 화살표와 인접 방면 라벨(예: 안동시
  방면)이 표시됨

3.5 현재 시각(t0) 타임라인

- 슬라이더는 "현재 시각(t0)"을 의미하며, P5=t0+5시간, P8=t0+8시간 시점의
  예측값을 그때그때 다시 계산

- t0를 옮기면 의사결정 제안서 14개 항목과 사이드바 읍면 상태가 함께
  갱신됨(확산이 진행될수록 해야 할 일이 바뀌는 것을 반영)

3.6 지역 감시 현황(사이드바)

- 18개 읍·면을 발화지점으로부터의 거리 기준으로 4단계 자동 분류:
  화재(발화지점) / 위험(현재 확산 반경 이내) / 주의(t0+5h 예측 반경
  이내) / 정상(그 외)

- 상단에 상태별 개수 요약, 하단에 상태 배지가 붙은 읍·면 리스트(화재
  항목은 강조 표시)

3.7 책임자

- 9/24 회의에서 서비스 대상을 개인 1인으로 확정한 데 따라, 화면의
  책임자는 항상 「의성군수」로 고정

- 이전 버전에 있던 의성군수/경상북도지사/산림청장 3단 지휘권 이관 탭은
  제거하고, 관련 내용은 의사결정 항목 S6(유관기관 동원)의 텍스트로만
  안내

3.8 의사결정 제안서 (14개 항목)

아래 6줄이 고정 형식으로 나온다.

5\. 알려진 제한사항 (목업 고지)

*⚠ 아래 항목은 시연을 위한 단순화이며, 실제 서비스 구현 시 정밀화가
필요하다.*

- 지도 위 읍·면 좌표, 산 위치 좌표는 제공된 이미지에서 육안으로 판독한
  근사치이며 실제 GIS 좌표가 아니다.

- 조건위험도·확산속도·피해면적 수치는 의사난수 기반 예시값이며 실제
  ELMFIRE 연산 결과가 아니다.

- 근거로 인용한 표준매뉴얼 조항·쪽수는 회의록에 기재된 내용을 그대로
  옮긴 것으로, 실제 문서 개정 시 달라질 수 있다.

- GPS 좌표 → 지도 픽셀 변환은 실좌표 2개 지점으로 보정한 근사
  선형식으로, 정밀한 GIS 정합이 아니다.

- 챗봇은 화면에 내장된 고정 근거자료만 사용하며, 실제 법령·매뉴얼
  데이터베이스와 실시간으로 연동되지 않는다.

6\. 남은 미결 사항 (9/24 회의록 연계)

아래는 9/24 회의록의 미결 이슈 중 이 목업과 직접 관련된 항목이다.

- 챗봇(QnA) 기능의 서비스 포함 여부 — 9/26 기능 회의 결과에 따라 이
  목업의 챗봇 기능이 제외될 수 있음

- 제안서 생성·갱신 방식(수동 트리거 / 주기 자동 / 이벤트 기반) 미정 —
  현재 목업은 "타임라인 슬라이더를 사용자가 직접 옮기면 즉시 재계산"하는
  방식으로 임시 구현

- SC-1a 렌더링 예 구체화 — 이 목업의 제안서 화면이 초안 역할을 겸함
