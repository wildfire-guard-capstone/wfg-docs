## 🔑 핵심 문제 인식 (이번 회의의 본질)

이번 회의는 "**우리가 만들 것을 아직 정의하지 못한다 → 정의하는 데 필요한 실제 정보가 없기 때문이다**"라는 하나의 문제로 압축된다.

### 만들려는 것 (서비스의 뼈대)
- **"역할(누가) + 상황(언제·어디) → 임무(무엇을·어떻게)"를 근거(왜)와 함께 제시하는 대응 판단 서비스.**
- 즉 이 서비스가 성립하려면 **누가·상황·무엇** 세 축이 구체적으로 채워져야 한다.

### 문제점 ① — "누가·상황·무엇"이 아직 구체화되지 않았다
- 그냥 '공무원·구조요원·진압요원'이라고만 두면 LLM은 의미 없는 답("공무원은 시민을 대피시키세요")밖에 내지 못한다. 역할·상황·임무가 실무 수준까지 특정돼야 쓸모 있는 출력이 나온다.
- 회의에서 이 부분이 아직 불명확하다는 점을 확인하고, **'역할'을 우선 산림청 소속으로 한정**하기로 방향을 좁혔다.

### 문제점 ② — 그 세 축을 채울 "실제 대응 프로세스"를 모른다 (근본 원인)
- 특정 좌표에서 산불이 났을 때 **"어느 상황실이 활성화되고, 누가 무엇을 하는지"** 현실에서 어떻게 돌아가는지를 팀이 모른다.
- 산림청 실무 매뉴얼만 확보돼 있고(전 기관 포함 표준 매뉴얼은 부재), 그마저도 '누가·무엇'이 명시적으로 딱 떨어지지 않아 정보 매핑을 직접 해야 한다.
- 이 도메인 공백 때문에 **서비스 범위·유즈케이스·필요 데이터가 전부 확정되지 못하고 있다.**

### 그래서 내린 결론 → 주말 액션 아이템 (§5)
문제점 ②(정보 공백)를 메우는 것이 나머지를 푸는 열쇠라고 보고, 주말 과제를 **두 갈래의 정보 조사**로 나눴다.
- **[1] 요구 데이터 조사팀** → "상황·무엇"을 채울 **데이터**가 실제로 존재·수집·활용 가능한지 확인.
- **[2] 산불 대응 프로세스 조사팀** → 산림청 주무관 문의로 **"누가·무엇"(실제 대응 프로세스)**을 확보하고, 이를 질문 프롬프트 구조로 정리.

> **한 줄 요약:** 만들 것("누가·상황·무엇" 대응 판단)은 정해졌으나 그것을 채울 **실제 산림청 대응 프로세스와 데이터를 모르는 것**이 이번 회의의 핵심 문제이며, 주말 과제 두 팀이 각각 그 공백을 메운다.

**② 요구사항 분석서 & 작업 분담**

- 쟁점: 프로토타입 완성 목표 시점.

- 쟁점: 필요 정보를 직접 검색해 찾을 수 있는지 vs 산림청에 직접 문의해야 하는지.

**④ 서비스 범위 좁히기**
- 논의: '누가(공무원/구조요원/진압요원)'가 누구인지 불명확. 범위를 너무 좁히면 쓸모없고, 넓히면 인프라·시간 부족. 대상을 산림청으로 한정하는 안.
- 쟁점: 시민 대피 전략을 포함할지.
- 결론: **보류** — 산림청 대상으로 좁히는 방향에 무게, 최종 범위는 미확정.

**⑤ LLM 아키텍처**

- 결론: **합의** — 단일 LLM + RAG 순차 구조로, 멀티에이전트는 보류.

## 4. 결정사항
- **VLM 미사용** — 분석 대상 이미지가 명확하지 않으면 불필요
- **서비스 방향을 '확산 예측'이 아닌 '대응 판단(대응 전략 수립)'으로** — 확산 예측은 기존 연구 다수, 대응 판단은 공백
- **LLM 출력은 '지시(하세요)'가 아니라 '근거 기반 추천/제안 + 사용자 상호작용(챗봇형)'** — 안전 직결이라 AI 단독 결정은 수용되지 않음
- **단일 LLM + RAG 순차 구조 채택**(멀티에이전트 보류) — 순차 처리로 충분, 인프라 한계
- **대상 사용자를 산림청 소속으로 좁힘** — 전 기관 대응은 시간·인프라 부족
- **프로토타입 화면(출력 정보)을 유즈케이스와 동시에 먼저 확정** — 화면이 있어야 유즈케이스가 명확해짐

  3. 실제 사용 가능한 유의미한 데이터인가? (데이터 분석 진행 — 예: "광진구에 소방서가 3개"(X) → "소방서가 A·B·C에 위치"(O))

### [2] 산불 대응 프로세스 조사팀 — 담당: 황승준·김지오·임성민

- **[3단계]** QnA보고서[1] + QnA보고서[2] → **종합 QnA보고서** 제작 → 이를 기반으로 질문 프롬프트 구조

  - (※ '역할'은 산림청 소속만으로 한정하자는 의견 반영)
