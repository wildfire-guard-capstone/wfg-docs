## 2. 민간협력 위기대응 사업 소개

### 추진 배경
- 2020년 코로나 당시 마스크 대란·백신 예약 문제 → 네이버·KT·LG 등 **민간 클라우드**를 활용해 공적 마스크 앱, 백신 예약 시스템 신속 개발
- 시사점: 정부 단독(재난문자·웹사이트 안내 등)보다 **민간 역량 + 기술**이 결합될 때 더 빠르게 대응 가능, 시민·기업도 위기 대응 주체가 될 수 있음
- 일회성 성공이 아닌 **지속 가능한 모델**로 만들기 위해 → 민간 클라우드 자원을 미리 확보하고 개발자가 활용할 플랫폼을 제공하는 것이 사업의 출발점

### 플랫폼 제공 내용
| 구분 | 내용 |
|---|---|
| AI·민간 클라우드 | 네이버·KT·NHN 클라우드 제공, AI 코딩(바이브 코딩) 도구 제공 |
| 공공데이터 | 흩어진 공공데이터를 한데 모아 개발에 활용하도록 제공 |
| 확산 지원 | 우수 프로젝트에 지자체 연결 등 확장·고도화 지원 |
| 공모전 | 사회현안 해결 공모전(본 챌린지) 운영 |

### 플랫폼 이용 절차
1. 민간협력 플랫폼 회원가입
2. **팀명, 대표자명, 사용자명** 등을 담당자 이메일로 발송
3. 플랫폼에서 사용 신청 → 승인기관 확인 후 전체 기능 승인
- 상세 안내: 플랫폼 상단 **사용자 가이드**, 유튜브 활용 영상 참고

### ⚠️ 이용 시 유의사항
- 클라우드는 **반드시 민간협력 플랫폼 로그인 → 디지털 자원 → 클라우드 메뉴**로 접속
  - 직접 접속 시 비용이 발생할 수 있으며, **사업 지원 대상이 아님**
- 공모전 **팀당 클라우드 계정 1개** 발급
- 클라우드 내 **AI 서비스 기능은 토큰 비용이 커서 지원 어려움**
- 계정별 비용을 모니터링 중 → 급증 시 연락 후 사용 방식 확인·조정 협의
- 지원 기간
  - 공모전 기간 중 지원, **중간 탈락 팀은 지원 중단**
  - **수상팀은 1년간** 플랫폼 사용 가능
  - 공모전 외 일반 프로젝트: 목적 적합성 검토 후 **3개월 단위 승인**, 연장 신청 없으면 회수

| 다른 공모전에 같은 주제로 냈다면? | 중복 지원에 해당. 단순 제출은 괜찮으나, **다른 곳에서 지원·수상 시 본 공모전 수상 취소 및 상금 환수** 가능 → 미리 알려줄 것 |

## 4. 우수사례 발표

### 4-1. 민관 합동 내비게이션 고도화 TF — 김영환 선임(NIA)

**문제 인식**
- 2022.8 서초동 도로 침수, 2023 오송 지하차도 침수, 2025 경북 대형 산불, 2026 관측 사상 첫 42℃ 돌파 및 전국 극한호우
- 기존 내비게이션은 도로·지하차도 **통제가 시작된 이후에만 알림(사후 알림)** → 통제 전 침수 위험을 운전자가 알 수 없음
- 산불 후 호우 → 산사태 같은 **복합·연계 재난**에도 대비 부족

**전환: 사후 알림 → 사전 경고**
- 내비게이션사에 실시간 API로 위험 정보 제공
- 알림 지점 **223곳(2024) → 933곳**으로 확대
- 산림청·행안부·국토부·지방국토청 등과 협업해 **산사태 연계 정보**까지 통합
- 경찰·지자체 현장 통제 전에도 화면 표출·음성 안내로 운전자가 스스로 위험 회피

**추진 경과**
| 시기 | 내용 |
|---|---|
| 2023.7 | 내비게이션 기업–과기정통부 첫 협의 |
| 2024.1 | 과기정통부 주축, 관계 부처·기관 + **국내 6개 내비게이션사** 참여 TF 정식 출범 |
| 2024.7 | 홍수기 전 6개 내비에서 홍수·침수 정보 사전 제공 시작 |
| 2025 | 홍수 심각 단계, 산사태 위험 정보 추가 / 연말 장애 대응 시스템 구축 |
| 2026.8~ | 국립공원공단 부분·전체 통제 데이터, 교통 돌발 정보 연계 확대 |

**핵심: 데이터 중계 아키텍처**
- 부처별로 흩어진 댐 방류, 홍수 심각 단계, 상습 침수구역, 급경사지, 국립공원 통제 정보 등을 **표준화·단일화**
- 과기정통부·NIA의 민간협력 플랫폼 기반 **표준 API**로 실시간 중계 파이프라인 구축
- 공공 서비스에 머무르지 않고 **네이버지도·카카오내비·T맵 등 6개 민간 내비**에 직접 제공 → 경로 탐색 시 경보 지역 표출, 진입 시 팝업·음성 알림

**성과**
- 2024 적극행정 우수사례 경진대회 **대통령상**
- 2025.12 과기정통부 부총리 표창

**메시지**: 공공데이터를 창의적 아이디어로 엮어 일상의 안전 문제를 해결하는 것이 참가자들이 가장 잘할 수 있는 일. 제2·제3의 내비게이션 TF 사례가 나오길 기대.

### 4-2. 고립·은둔 청년 생활 개선 플랫폼 '빛나길' — 작년 금상 팀(서버 개발자 발표)

**사회 현황**
- 국내 은둔 경험 청년 **54만 명 이상**, 우울 비율 32%, 연간 사회적 비용 약 **7조 원**
- 생활 루틴 부재: 불규칙한 식사 27%, 밤낮 바뀐 경험 52%

**기존 지원의 한계**
1. **신청·방문 구조** — 집 밖에 나오기 어려운 청년에게 진입 장벽이 높음
2. **낙인** — 스스로를 '고립 청년'으로 규정해야 하는 불편함
3. **연결 공백** — 프로그램 종료 후 일상을 다시 세울 지원이 없음

**접근 방식**: 상태를 규정하지 않고(고립·은둔·외톨이 등 단어 배제) **행동 중심**으로 하루를 만들어 가기

**3가지 차별점**
1. **감정 기록** — 6가지 감정(평온함, 만족감, 활기참, 불안함, 무기력함, 피로감) 중 선택·시각화, 한 달 단위로 돌아보기, 상태 기반 루틴 추천
2. **루틴 세분화** — 예: 산책 → 옷 갈아입기 / 외출 / 한 바퀴 돌기 / 귀가로 쪼개 작은 성공 경험 제공. 난이도 3단계(가볍게 / 조금 신경 써서 / 의지를 다잡고), 5개 카테고리(쉬어가요 포함)
3. **사회 참여 연결** — 외출 루틴 중 고장 난 가로등·파손 도로 등을 촬영·제보 → GPS 자동 수집 → 운영팀이 지자체에 대리 접수 → 처리 결과를 사용자에게 알림 → **효능감 회복**

**운영 현황**: 누적 가입자 약 472명, 누적 루틴 완료 약 628건

**향후 계획**
- **지자체 담당자 연계**: 3일 연속 미접속·부정 감정 시 관리자 화면 표시, 단계별 담당자 알림, 상담 기록 연결
- 루틴·제보 우수자 **인센티브**
- **비재촉형 푸시 알림**: 방해 금지 시간 설정, 감정 미등록 시 저녁 리마인드, 성취 알림
- **개인정보 분리 구조**: 이름·생년월일·주소를 보유하지 않고 사용자 인덱스로 기관 DB와 연결
- 로드맵: 2026 4분기 담당자 연계 베타 출시 → 2027 상반기 복지센터 등 지자체 시범 협력 → 2027 하반기 협력 지역 확대, 제보 데이터 기반 사각지대 분석

**공모전 소감**: 팀원들의 동력을 유지하는 계기가 됨. 종료 후에도 관계자를 통해 지자체 연결·인프라 지원을 받고 있어 서비스를 지속할 수 있었음.
