## 1조 발표 요약

**주제:** CCTV 기반 이상 행동 탐지 및 관제 시스템

- 두 개의 영상 입력에 대해 이상 행동 탐지 → 사건 생성 → 근거 설명 → 피드백까지 이어지는 파이프라인 구현 목표

## 2조 발표 요약

**주제:** 다중 CCTV 기반 위험 상황 탐지 및 설명 가능한 AI 관제 시스템

- 기존 한계: 단일 시점 사각지대, 카메라 간 연계 부재, 설명력 결여 (관제 요원 1명당 CCTV 477대)
- 탐지 대상: 배회, 추종, 침범
- 파이프라인: 영상 입력 → YOLO 탐지 → ByteTrack 추적 → 위험 행동 판별 → VLM 설명 → 관제 로그
- VLM은 위험 임계치 초과 시에만 호출하여 오버헤드 최소화
- 검증: mAP/Precision/Recall (탐지), ID F1/ID Switch (추적), Macro F1 (행동 분류)

### 교수님 피드백
- 위험 행동 선정 근거 명시 필요
- 모델 버전 고정 및 선정 이유 서술 (예: YOLOv8 medium)
- 실시간 기준 정의 필요 (애플리케이션 맥락에 따라 다름)
- 정량적 목표 수치 제시 필요

## 3조 발표 요약

- 모듈: 데이터 수집, 혼잡도 AI 예측, 조회 API 최적화, 사용자 UI

### 교수님 피드백

- 정량적 목표 수치 부재
- LSTM 등 알고리즘 선정 이유 없음 → 후보 알고리즘 비교 및 선정 근거 서술 필요

## 4조 발표 요약

**주제:** 전기차 충전소 혼잡도 예측 추천 서비스 (EV Flow)

- 대상: 급속 충전소, 광진구 22개소 54기 우선
- 이동 거리 + 예상 대기 시간 + 미래 혼잡도를 통합 추천 점수로 결합, 상위 3개 충전소 추천
- 기술 스택: React / FastAPI / PostgreSQL + Redis / XGBoost / Docker
- 정량 목표: F1 0.75↑, ROC AUC 0.80↑, 대기 시간 오차 5분 이내, 추천 적중률 85%↑, 응답 0.5초

### 교수님 피드백
- 문제 → 목표 → 수행 방안 → 일정 → 차별화가 논리적으로 연계되어야 함
- 차별점은 기존 시스템과 명확한 비교 형태로 제시
- 평가 기준 수치의 설정 근거 서술 필요

## 5조 발표 요약 (우리 팀)

**주제:** 산불 확산 예측과 근거 기반 대응 의사결정 지원 시스템

### 배경
- 2025년 산불: 건수 평균 대비 -13%, 피해 면적 **7.3배**
- 국가 시스템은 확산 예측까지 가능하나 **예측 → 행동 판단 번역 구간 공백**
- 역할별(진압대원/구조요원/공무원/시민) 필요 정보가 다름에도 동일한 대응책 전달 중

### 핵심 목표
발화지점, 관측시각, 사용자 역할 **3가지 입력**만으로 역할 맞춤형 대응 보고서 자동 생성

### 차별성
- 확산을 새롭게 예측하는 것이 아님
- **예측 이후 대응 판단 자동화 + 조항 단위 근거 검증**이 핵심
- 5종 가드레일: 근거 부재 / 수치 환각 / 위험 조언 / 논리 모순 / 역할 위반

### 아키텍처 (파이프라인)
```
[사용자 입력 + 기상 데이터 + 사전 구축 격자]
        ↓
   상황 케이스 파일 생성
        ↓
  확산 시뮬레이션 (3개 물리 모델, IoU 기반 파라미터 보정)
        ↓
  골든타임 = 화선 도달 시간 - 대피 예상 시간 (음수 → 최우선 경고)
        ↓
  LLM 보고서 생성 (Qwen 3.5 27B + LoRA 파인튜닝)
        ↓
  RAG 근거 검증 (임베딩 + BM25 혼합 검색)
        ↓
  5종 가드레일 필터링
        ↓
  역할 맞춤 대시보드 출력
```

### 데이터
- AI허브 샘플 560개 전수 조사 → 시계열 이력/근거 라벨 없음
- 확산: 물리 모델 사용 (지도 학습 불가)
- 근거: 외부 법령/매뉴얼에서 별도 확보

### 성능 평가 지표
| 항목 | 지표 |
|------|------|
| 위험도 | Macro F1, QWK Score |
| 확산 | IoU, 면적 교차율 |
| RAG 검색 | 정답 조항 검색 비율 |
| 생성 | 문장 지지율, 인용 정확도 |
| 안정성 | 가드레일 검출률, 오차단 비율 |

### 에뮬레이션 실험 계획
1. 프롬프트 기준선 vs LoRA 파인튜닝 비교
2. 확산 모델 미적용 vs 적용 비교
3. RAG 검증 미적용 vs 적용 비교

### 팀 구성
- 백엔드 2명, 프론트엔드 1명, AI 1명
- 전원 AI 관련 작업 최소 1개씩 분담

## 5조 교수님 피드백

### 긍정 평가
> "다른 팀보다 구조적으로 잘 되어 있다" — 교수님

### 보완 사항

**1. 예측과 의사결정 분리 명확화**  
현재 예측 내용은 충분하나 의사결정 항목과 목표가 불명확  
→ 두 영역을 분리하여 각각의 목표 수치 설정 필요

**2. 시스템 개요도 추가**  
많은 내용을 글로만 설명 → 전처리/데이터/AI 모델/평가를 한눈에 볼 수 있는 다이어그램 필수

**3. 모델 선정 근거 보완**  
Qwen 선정 이유가 "익숙해서"에 그침 → 대안 모델과 비교 검토 필요

**4. 중국산 모델 보안 이슈 검토**  
공공 사업/기업 환경에서 중국산 모델 사용 제한 사례 多  
→ Llama, Mistral 등 대안 모델 검토 권장

**5. 개발 환경 명시**  
GPU 서버 사양, OS, 라이브러리 버전 등 구체적으로 기술
